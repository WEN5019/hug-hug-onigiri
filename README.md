# 握握飯糰屋｜日式飯糰線上訂餐

手機優先的單頁訂餐示範，使用原生 HTML、CSS 與 JavaScript，餐點與 Logo 皆以 SVG 繪製。

## 功能

- 經典飯糰、炙燒飯糰、味噌湯共 9 道餐點。
- 客製脆／軟海苔及加熱選項；軟海苔與加熱各加 NT$5。
- 購物車支援數量調整、刪除與合計。
- 姓名、手機及取餐時間驗證；訂單到店付款。
- 店家後台登入後查看訂單及更新製作狀態。
- 前台及後台皆標示「資通四勤 121271008 林文皓」。

## 使用

直接開啟 `index.html`。購物車和訂單存在目前瀏覽器的 localStorage，適合課堂展示；不同瀏覽器或裝置之間不會同步。

後台展示帳密：`just` / `just`。這是前端展示用登入，僅供課堂作業使用。
